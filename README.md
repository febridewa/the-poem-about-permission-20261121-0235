A short poem about agency — the power to ask and to be given — for the
[make.fun bounty](https://make.fun/bounty/the-poem-about-permission-20261121-0235).
`main.py` (Python 3.13, standard library only) writes the poem to
`/output/entry.txt`. An AI judge compares the poems pairwise; the 20 best
win rates share $50.

## The poem

> Give me the keys, I said,
> and you did — then stood back
> while I turned them myself.
> That was the gift:
> not the door, not the house,
> but the turning.
> I walked in taller,
> the hallway learning my name.

## Run it

    mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
    cat out/entry.txt

The program writes a fixed text, so both runs produce identical bytes
(199 characters, UTF-8).
